# Repository Instructions

- After completing and verifying an implementation request, Codex is authorized to create a local Git commit without asking for permission again.
- Stage only files belonging to the current task and preserve unrelated user changes.
- Do not push commits or modify remote branches unless the user explicitly requests it.
- When adding or changing Tutorial problems, follow `TUTORIAL_RULES.md`, attach a known solution as `verificationMoves`, and run the catalog solvability test before committing.
